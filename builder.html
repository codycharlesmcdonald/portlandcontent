Publish

Publishing puts the page at portlandcontent.com/…, unlisted and hidden from search. It goes live about a minute later. Publishing again replaces it.

Connect this browser once. Publishing needs a GitHub key that stays on this device only.

  1. Open github.com/settings/personal-access-tokens/new and sign in.
  2. Name it "Proposal builder" and set Expiration to 1 year.
  3. Under Repository access pick "Only select repositories", then "portlandcontent".
  4. Under Permissions, Repository permissions, set Contents to "Read and write".
  5. Click Generate token, copy it, and paste it below.
