# Portland Content site

Static site generated from `basecamp-tools/docs/mockups/portland-content-mockup.template.html` by the build script in the web design thread. Pages: index, services, work, case. Styles in style.css, images in img/. Deploy: copy this folder to the public `portlandcontent` repo (GitHub Pages, main branch, root). Add a `CNAME` file with `portlandcontent.com` once DNS points at Pages.
